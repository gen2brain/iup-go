## ZORDER (write-only) (non-inheritable)

Change the ZORDER of a dialog or control.
It is commonly used for dialogs, but it can be used to control the z-order of controls in a dialog.

### Value

Can be "TOP" or "BOTTOM".

### Notes

Has no effect in GTK 4, FLTK, Haiku and Android.

### Affects

All controls that have visual representation.
