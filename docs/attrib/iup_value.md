## VALUE (non-inheritable)

Its behavior is element-dependent. It is often used to change the control's main value, such as the text of an [IupText](../elem/iup_text.md). See each element's documentation for the meaning of VALUE on that element.

For the [IupRadio](../elem/iup_radio.md) and [IupZbox](../elem/iup_zbox.md), it is the child selected among the others in the composition. Set it to the name of a child, previously associated with [IupSetHandle](../func/iup_sethandle.md). The child can also be set or retrieved by its handle through the VALUE_HANDLE attribute.
